# 学年別ふりがな P1

ローカル実装・検証。公開サイトへの反映、コミット、Push、デプロイは行っていません。

## 操作

1. Homeの「学年別ふりがな」で原文と小学1〜6年生を選び、「対象を確認する」を押す。
2. 文章中の漢字の枠を押して、読みを入力する。初期範囲は漢字の連続部分。選択後は読み欄へフォーカスする。
3. 「1字ずつに分ける」で本体の論理単位ごとに分割し、間の「結合」または編集欄の「右隣の漢字と結合」でまとめる。
4. 「次の読み未入力へ」で未習漢字を含む未入力範囲へ移動する。

熟字訓を一字ずつ推定しない。今日→きょうは語全体で指定する。大人など全字既習の範囲も読みを保存できるが、既習字だけなら表示・コピーには使わない。分割・結合した範囲の読みは安全に再配分できないため消去し、事前に説明する。他の範囲の読みは保持する。

## 判定と状態

- EducationKanjiDiagnostics.AnalyzeTextのUnlearnedItemsとReasonを使用。独自データ・漢字判定・字形変換なし。
- 選択学年までの累積配当を既習とする。音訓の指導段階は混ぜない。
- 最大2,000 UTF-16単位。超過は切り捨てない。不正UTF-16は位置と理由を表示して生成を止める。
- IVS/SVSと補助漢字を本体の論理単位として保持。VS付きの原表記は配当表外として対象。
- 手動範囲は原文版・開始位置・長さ・対象表記に結び付ける。同じ語の別出現へ転用しない。
- 学年変更は診断だけ更新し、範囲・読みを保持。同じ原文版の再生成でも保持。
- 原文を編集すると現プレビュー・編集・コピーを停止。旧結果は「旧版・編集とコピー不可」の閉じた参照欄だけに置く。元の文字列へ戻しても別原文版となる。
- 画面切り替えはコンポーネントを破棄せず状態を保持。永続保存なし。

## 表示とコピー

構造化したFuriganaPartをRazorでruby/rtまたはspanとして描画する。HTML文字列をMarkupStringへ変換しない。

FuriganaPresentationを表示とコピーで共有する。

| 状態 | プレビュー | コピー |
| --- | --- | --- |
| 未習を含む範囲・読みあり・表示ON | ruby | 表記（読み） |
| 全字既習 | 原文 | 原文 |
| 読み未入力 | 原文、点線下線で要確認 | 原文、架空の読みを付けない |
| 表示OFF | 原文 | 原文 |
| 原文変更後 | 現プレビューなし、旧版を別欄に保持 | 操作を提供せず、サービスも拒否 |

読みは200 UTF-16単位以内。制御文字、不正UTF-16を拒否。読み入力のエラー中はコピーを無効化し、未保存であることを表示する。

## 構成

- FuriganaService: 入力検証、教育漢字診断、Reasonの分類。
- FuriganaDocument: 原文版、診断、手動範囲、分割・結合。
- FuriganaSession: 現入力と旧結果の整合性、学年・表示状態、編集・コピーのガード。
- FuriganaPresentation: ルビ範囲決定、構造化表示、括弧付きコピー。
- FuriganaPanel / FuriganaPreview: UI操作と安全なRazor描画。

将来の読み解析adapterは原文とUTF-16範囲・表層読みを受け渡す位置に追加できる。P1には未使用の解析interfaceや外部ライブラリを導入しない。

## 操作性と未検証

数値で範囲を指定させず、語全体は枠選択と読み入力、一字分割はボタン1回にした。未入力移動と自動フォーカスで連続入力の操作を減らした。

長い連続漢字から複数の熟語を作る場合は、一字分割後の結合を繰り返す必要がある。次段階では文字間をクリックしてその場所だけ分割する操作、複数枠を選択して一括結合する操作が改善候補。原文編集後の読みに自動追従しないため、再入力が必要。

実機iOS/Android、日本語IMEの実機入力、スクリーンリーダー、Pages上の配信・コピー権限、長文の端末別性能は未検証。今回のモバイル確認はブラウザviewportによるもの。
